# 家族・親子 感動ストーリー台本 量産指示書 v2
## (20〜30分動画向け/多ジャンル対応/オリジナル性担保)

---

## 第0部:v2の設計思想

元エッセイは「参考事例の1つ」に格下げする。v1では元文章の技法(気づきの遅延、かき揚げ的な日常動作など)を必須原理にしていたが、それでは全話が元文章の変奏=パクリになる。

v2では、**感動を駆動する「エンジン」を8種類に分解**し、元エッセイの技法はエンジン1に過ぎない位置づけにする。毎回異なるエンジンを選ぶことで、構造レベルから別物の話が生まれる。

## 第1部:感動エンジン16種(物語の駆動原理)

毎回1つを主エンジン、必要なら1つを副エンジンとして選ぶ。**主エンジンが変われば、同じ題材でも全く別の話になる。**

**このリストは閉じた選択肢ではない。** エンジン同士の掛け合わせや、ここにない新しい駆動原理の発明は常に歓迎。良い新エンジンが生まれたら管理表に追記してリスト自体を育てていく。

### エンジン1:遅効性の気づき
その場で流した言葉・出来事が、後から本当の重さで届く。
(元エッセイ型。使用頻度は全体の1割程度に制限)

### エンジン2:秘密の開示
物語の後半で、隠されていた事実が明かされる。
例:無愛想な父が毎晩こっそり子の弁当箱を洗って研究していた/亡き母の通帳に「◯◯の結婚式用」の積立
→ 前半に「不可解な行動」を伏線として散らし、後半で回収。ミステリー的快感と感動の両立。

### エンジン3:立場の反転
かつてされた側が、する側になって初めて理解する。
例:反抗して家を出た娘が、自分の娘の反抗期に直面する/おぶってもらった背中に、今度は親をおぶう

### エンジン4:すれ違いと和解
誤解・確執が長年続き、ある出来事で氷解する。
例:20年口をきかない父子が孫の誕生で/事業に反対した父が、実は最初の客だった
→ 20〜30分尺と最も相性が良い。確執の歴史をじっくり描ける。

### エンジン5:継承
技術・味・口癖・価値観が世代を超えて受け継がれる。
例:潰れた食堂の味を再現しようとする娘/母の育児日記と同じ言葉を、自分が我が子に言っていた

### エンジン6:限られた時間
余命・別離・老いなど、タイムリミットの中での関わり。
→ 強力だが濫用すると陳腐化。全体の2割以下に。

### エンジン7:血縁を超える家族
血の繋がらない関係が家族になっていく過程。
例:再婚相手の連れ子が初めて「お父さん」と呼ぶ日/亡き親友の子を引き取った独身男性

### エンジン8:小さな日常の再発見
劇的な事件は起きない。ありふれた習慣・風景の価値に気づく。
例:毎朝の「行ってらっしゃい」が録音に残っていた/父の唯一の趣味だった日曜の洗車、その助手席
→ 静かな感動系。文章力で勝負するタイプ。

### エンジン9:誇りの発見
恥じていた・軽んじていた家族を、誇りに思う瞬間が訪れる。
例:参観日に来てほしくなかった作業着の父、その仕事ぶりを偶然見てしまう/ダサいと思っていた母の内職が、実は自分の学費のすべてだった

### エンジン10:償い
過去の過ちを抱えた側が、それを取り戻そうと生きる物語。完全には償えない不完全さがエモさの核。
例:娘の運動会に一度も行けなかった父の、孫の運動会/若い頃母を泣かせた息子が、認知症の母に毎週会いに行く

### エンジン11:遺志の代行
故人のやり残したことを、残された家族が果たす。
例:母が応募し続けて落選し続けた川柳、遺句で初入選/父が定年後に行くはずだった場所へ、遺影と旅する

### エンジン12:視点の反転再生
前半で描いた出来事を、後半で相手側の視点から見せ直すと、すべてが違う意味に見える。
例:「門限にうるさい母」パートの後、母視点で同じ日々を再生すると、うるささの裏の事情が見える
→ 構造自体が伏線回収になる強力な型。20〜30分尺でこそ活きる。

### エンジン13:気づかれない愛の完遂
愛情が本人には最後まで伝わらない。**視聴者だけが知っている**ことで生まれる切なさと尊さ。
例:息子は最後まで気づかなかったが、毎月の「会社の食事会」は父が抜いた自分の昼食代だった——ナレーションだけが真実を語る

### エンジン14:恩送り
親から受けたものを、親に返すのではなく別の誰か・次の世代に渡すことで愛が完成する。
例:苦学を支えてくれた亡母への恩を、同じ境遇の学生への支援で返す/血の繋がらない自分を育てた養父と同じことを、自分もする

### エンジン15:力関係の更新
子が親を超える日、親が子に初めて頭を下げる日、守る側と守られる側の交代。
例:父の店の危機を、反対されていた息子の仕事が救う/初めて「お前の言う通りだった」と言った頑固な父

### エンジン16:泣き笑いの遺産
ユーモアで愛を伝える家族。ふざけた形見、変な家訓、笑える口癖が、後から涙に変わる。
例:形見分けが「くだらない土産物コレクション」だった父、その一つ一つに付箋のメモが/葬式で流すよう遺言された選曲が全員を笑わせ、泣かせる

## 第1.5部:最重要原則——納得感とエモさの設計(全エンジン共通)

**軸やエンジンの管理はあくまで「被り防止」の道具。作品の価値を決めるのは、転の納得感と心に残るエモさ。**両者が衝突したら、常にこちらを優先する。

### 逆転の納得感を作る4条件
1. **転は「再解釈」で作り、「新情報のちゃぶ台返し」で作らない**:転で明かされる真実は、前半に既に見せた出来事・セリフ・行動の意味が変わるものに限る。前半に一切登場していない人物や事実で逆転させると、驚きはあっても納得感がない
2. **伏線は「二度目に見ると意味が変わる」型にする**:一度目は日常描写として自然に流れ、真相を知った後に思い返すと胸に刺さる——この二重性が理想。「いかにも伏線」な思わせぶりは逆効果
3. **行動の一貫性**:真相が明かされた後から振り返って、その人物の全行動が一本の動機で説明できること。「あの時のあれも、これも、全部そうだったのか」と繋がる瞬間が納得感の正体
4. **感情の因果を飛ばさない**:憎しみが一瞬で感謝に変わる展開は嘘くさい。転の後、感情が変わるまでの戸惑い・沈黙・時間経過を必ず描く

### 心に残るエモさの源泉5つ
1. **語りすぎない**:一番言いたいことほど、セリフやナレーションで説明しない。行動・物・沈黙に語らせる。「愛していた」と書いた瞬間にエモさは死ぬ
2. **具体の力**:感情は抽象語ではなく固有のディテール(商品名、金額、方言、言い間違い)に宿る。「質素な弁当」ではなく「卵焼きと、隅にいつもの蛸さんウインナーが2つ」
3. **不完全性**:完璧な親、完璧な和解は嘘くさく、心に残らない。言えなかった一言、間に合わなかった後悔、それでも残るもの——欠けている部分が視聴者自身の記憶と接続する
4. **非対称の愛**:与えた側は覚えていて、受けた側は忘れている(またはその逆)。この非対称が発覚する瞬間が最もエモい
5. **視聴者の家族を思い出させる**:目標は「この話に泣く」ではなく「これを見て自分の親に電話したくなる」。普遍的な家族の風景(食卓、送り迎え、口癖)を必ず織り込む

### 柔軟性の原則
- 本指示書の全リスト(エンジン・軸・例)は**発想の呼び水と被り防止の語彙**であり、閉じた選択肢ではない。リスト外の発想が浮かんだら常にそちらを優先してよい
- 型に従った結果として納得感やエモさが損なわれるなら、型を破る。チェックリストは「守れているか」ではなく「破る価値があったか」を問うためのもの

## 第2部:関係性マトリクス(チャンネルの主軸)

**このチャンネルは「家族の感動話」専門。多様化はジャンルの拡散ではなく、家族内の関係性の掘り下げで実現する。** 「親子もの」と一括りにせず、誰と誰の・どの人生段階の関係かまで分解すれば、それだけで50通り以上の"別の物語"になる。

**【重要】以下の全軸のリストと例は「開いたリスト」である。** 列挙されているのは発想の呼び水と被り管理用の語彙であって、この中から選ばなければならない縛りではない。リスト外の関係性・節目・アイテムを自由に発明してよく、むしろリスト外の具体を出せた回のほうが被りにくく質も上がる。新しく使ったものは管理表に追記し、リスト自体を育てる。

### 軸A:関係性(最重要軸)※各話で必ず1つに絞る

**A-1 親子(縦の関係)** ※性別×ライフステージで別物になる
1. 母と幼い息子/娘(乳幼児〜小学生)
2. 母と思春期の息子/娘
3. 母と成人した息子/娘
4. 父と幼い息子/娘
5. 父と思春期の息子/娘(最もすれ違いを描きやすい)
6. 父と成人した息子/娘(結婚・仕事を巡る確執と和解)
7. 老親と中年の子(介護・看取り・立場の逆転)
8. 亡き親と残された子(遺品・記憶を通した対話)
9. シングルの親と子(母子家庭/父子家庭)
10. 継親・養親と子(血縁を超える関係の構築)

**A-2 夫婦(横の関係)** ※親子ものとは感動の質が異なる。恋愛ではなく「共に生きた歳月」を描く
11. 新婚〜子育て期の夫婦(すれ違いと再確認)
12. 熟年夫婦(会話がなくなった二人の再発見)
13. 定年後の夫婦(初めて向き合う長い時間)
14. 老老介護の夫婦
15. 死別した配偶者への想い(遺された日記、初めて知る本心)
16. 再婚同士の夫婦(互いの過去ごと受け入れる)
17. 金婚式・銀婚式(50年分の伏線回収ができる最強の節目)

**A-3 きょうだい**
18. 兄と弟/姉と妹/兄と妹/姉と弟(組み合わせで力学が変わる)
19. 年の離れたきょうだい(親代わりだった兄・姉)
20. 双子
21. 確執のあるきょうだい(相続、親の介護の押し付け合い→和解)
22. 亡きょうだい(早逝した兄弟の分まで生きる)

**A-4 世代を飛ぶ関係**
23. 祖父母と孫(親には言えないことを言える関係)
24. 曽祖父母と曾孫(戦争の記憶の継承)
25. 祖父母に育てられた孫

**A-5 姻族(結婚でつながる家族)** ※感動系で意外に手薄な鉱脈
26. 嫁と姑(確執→本当の親子になる)
27. 婿と舅(無口な男二人の距離が縮まる)
28. 義理のきょうだい

### 軸B:舞台・背景(関係性を置く「場所」。ジャンルではなくあくまで背景装置)
現代の共働き家庭/昭和・平成の風景(団地、駄菓子屋、黒電話)/家業(食堂、農家、漁師、町工場)/闘病・介護の日々/単身赴任・上京・離れて暮らす/受験・部活・習い事/貧しかった時代/遺品整理・実家の片付け/毎日の食卓・台所
→ **主役はあくまで軸Aの関係性。背景が話の主題にならないよう注意**(例:「甲子園の話」ではなく「甲子園を通して見える父子の話」)

### 軸C:視点人物
当事者本人/相手側(同じ話を子視点で書くか親視点で書くかで別物になる)/亡き人(手紙・録音形式)/第三者(孫が見た祖父母夫婦、担任が見た親子)

### 軸D:時代設定
戦後復興期/高度成長期/バブル期/平成初期/2000年代/現代
※二時代をまたぐ回想構成は選択肢の一つに過ぎない。現代だけで完結する話、一日の出来事だけを描く話も同等に有効。時間の扱い(またぐ/またがない/一日もの)自体も被り管理の対象にすると単調化を防げる

### 軸E:人生の節目(関係性ごとに固有の節目がある)
- 親子系:初めての一人外出/卒園・卒業/受験/反抗期/就職・上京/結婚/出産/介護開始/看取り/遺品整理/成人式/初任給/子の不登校
- 夫婦系:結婚記念日/定年退職の日/子どもの独立(二人に戻る日)/金婚式/病の告知/どちらかの入院/引っ越し・家の建て替え
- きょうだい系:実家の売却/親の法事での再会/相続/きょうだいの結婚式/親の介護分担

### 軸F:象徴アイテム ※カテゴリであって選択肢ではない
以下は「カテゴリの見本」。実際のアイテムは毎回その物語固有の具体物を発明する(カテゴリ「料理」→具体は「隅が焦げた卵焼き」「日曜だけのナポリタン」「梅干しの塩加減」…と無限)。**被り管理はカテゴリ名ではなく具体物の一文要約で行う**ため、同カテゴリの連続使用は具体が違えば問題ない。
カテゴリ見本:料理・味/衣類・靴/手書きの記録/音声・映像/道具(仕事道具、楽器、グローブ)/身体(手、背中、身長の傷)/習慣・儀式/場所/言葉・口癖/金銭(貯金通帳、仕送り、ポチ袋)/乗り物/植物/——その他自由

### 軸G:感情の変換式
寂しさ→嬉しさ/後悔→赦し/誤解→和解/反発→尊敬/憎しみ→理解/当たり前→かけがえのなさ/疎ましさ→愛おしさ/悲しみ→継承/劣等感→誇り/恐れ→信頼

### 軸H:結末の型
1. 祝福型(見送って終わる) 2. 再生型(壊れた関係が結び直される) 3. 継承型(次の世代へ渡して終わる) 4. 追悼型(亡き人への感謝で終わる) 5. 循環型(冒頭のシーンに戻り、意味が変わっている) 6. 余韻型(答えを明示せず、象徴アイテムの描写で終わる)

### 軸I:転の仕掛け(何が明かされるか)※品質の生命線
設定を変えても「転」が同じだと視聴者には同じ話に見える。AIが収束しやすい頻出パターンを分解し、必ずここから指定・管理する。
1. 隠れた金銭的犠牲(こっそり積み立てた通帳、身銭を切っていた仕送り)
2. 隠れた労力・習慣(毎晩の弁当研究、こっそり直されていた自転車)
3. 隠していた病・痛み(本人が最後まで言わなかった)
4. 隠していた過去(親の生い立ち、戦争体験、前職、初恋)
5. 記録の発見(日記、手紙、母子手帳、録音、ビデオ、SNS下書き)
6. 第三者の証言(先生・同僚・隣人だけが知っていた一面)
7. 本人の口からの告白(生前・和解の場での直接の言葉)
8. 誤解の反転(冷たいと思っていた行動の真意が逆だった)
9. 同じ行動の再現(自分が親と同じことを無意識にしていた)
10. 物の来歴の判明(ずっとあった物に隠された意味があった)
11. 相手も同じ想いだった(すれ違っていた二人の想いが同型だった)
12. 約束の実行(忘れられたと思っていた昔の約束が果たされていた)

**多様性の担保:エンジン8 × 関係性28 × 背景9 × 視点4 × 時代6 × 節目25 × アイテム12 × 変換10 × 結末6 × 仕掛け12 = 家族ネタ限定でも理論上数億通り。ただし多様性の実感を決めるのは組み合わせ数ではなく「直近の被り」なので、第6部のローテーション管理を必ず併用する。**

## 第3部:20〜30分尺の構成設計(起承転結×離脱防止)

### 尺と文字数
朗読・ナレーション動画の標準速度は約300字/分。
- 20分 ≒ 6,000字
- 30分 ≒ 9,000字
- 間・BGM演出を考慮するなら本文5,500〜8,500字を目安に

### 基本思想:「結で満たす」と「途中で離脱させない」は矛盾しない
起承転結の弱点は「結までが長い」こと。対策は結を早めることではなく、**「大きな満足は結まで取っておき、途中には"小さな報酬"と"未回収の謎"を絶やさない」**こと。視聴者は「答えが気になる状態(オープンループ)」の間は離脱しない。

### 起承転結×6幕の対応と離脱防止装置

| 構成 | 幕 | 尺配分 | 内容 | 離脱防止装置 |
|---|---|---|---|---|
| **起** | ①コールドオープン | 5% | 転(クライマックス)の直前シーンを冒頭に一瞬だけ見せてから時間を巻き戻す。「あの日、母が差し出した通帳の意味を、私はまだ知らなかった——話は3年前に遡る」型 | **ループ①(最大の謎)をここで開く。**冒頭30秒=150字が勝負。状況説明・自己紹介から入らない |
| **起** | ②日常と関係性の確立 | 15% | 人物の性格を具体エピソードで見せる。笑い・共感を入れる | 3分以内に「小さな違和感」を1つ混ぜる(不可解な習慣、触れられない話題)=**ループ②** |
| **承** | ③亀裂・変化の発生 | 20% | すれ違い・確執・環境変化。物語が動き出す | 10分地点(離脱の第一の谷)に**小さな開示**を置く=ループ②を回収し、同時に**ループ③を開く**。「謎を1つ返したら1つ開く」の交換を守る |
| **承** | ④深化・積み重ね | 20% | 時間経過、エピソードの蓄積、伏線埋め込み | 各場面に「ミニ感情の山」(小さな優しさ、小さな衝突)。**同一シーン4分以上禁止。**場面転換は「それから五年後——」と明示ジャンプ |
| **転** | ⑤真相・転換点 | 25% | ループ①(冒頭の謎)をここで回収。秘密の開示・気づき・和解。感情の最高到達点 | 20分地点(第二の谷)がちょうど転の入口に来るよう設計する。回収は一気にではなく**2段階**(まず事実→次にその裏の想い)にすると滞在が伸びる |
| **結** | ⑥満たしの着地 | 15% | 心が満たされる結末。冒頭シーンに戻り、同じ光景が全く違う意味に見える(循環構造) | 転で泣かせた後、**結では静かな幸福・未来への開き**で「観てよかった」という読後感に変換。ここが高評価・コメント・次回視聴を生む |

### 離脱防止の5原則
1. **オープンループ常時1個以上**:どの時点で切っても「未回収の謎」が最低1つ残っている状態を維持する。全部回収し終わるのは⑤の終わりだけ
2. **冒頭150字ルール**:最初の30秒に「結末への予感」か「強い違和感」。ここで掴めなければその後の出来はほぼ無関係に離脱される
3. **報酬の分割払い**:感動を1箇所に全ベットせず、10分・20分地点に中規模の山、幕ごとに小さな山。ただし**最大の答えは絶対に転まで温存**する
4. **回収と開示の交換則**:謎を1つ解いたら、その解答が新しい疑問を生む形にする(「送金の主は父だった→ではなぜ父は名乗らなかった?」)
5. **タイトル・サムネの約束は転で果たす**:サムネで見せた場面・文言が動画のどこで出るか分からない状態が、実は最強の視聴継続装置。冒頭で約束を果たすと即離脱される

### 「結で満たす」ための着地技術
- 転(涙)と結(満たされ)を明確に分ける。転の直後に終わると「泣かされただけ」の消耗感が残る。結で**日常が続いていく描写**(いつもの食卓、いつもの挨拶——ただし意味が変わっている)を1〜2分入れることで、視聴後感が「切ない」から「あたたかい」に変わる
- 最後の一文は象徴フレーズの再登場(意味変え回収)か、未来へ開く一言で締める
- ネガティブ(死・後悔)で終わる話でも、最終カットは必ず「継承」「感謝」「新しい朝」などの上向きの画で終える

## 第5部:量産運用ルール

1. **関係性のローテーション**:親子ものに偏りやすいので、親子:夫婦:きょうだい:祖父母孫・姻族 = 4:3:2:1 程度の配分を意識する。夫婦もの・嫁姑ものは競合チャンネルが手薄な差別化ゾーン
2. **エンジン使用比率の上限**:エンジン1(元エッセイ型)とエンジン6(余命・死別)はそれぞれ全体の2割以下。感動系チャンネルが陳腐化する最大要因は死別ネタの濫用
3. **時代考証チェック**:昭和の話にLINEを出さない、2000年代にスマホを出さない等。時代ディテールの正確さが長尺の没入感を左右する
4. **完成後チェックリスト**:
   - □ 冒頭150字(30秒)にコールドオープンの謎があるか
   - □ どの時点で切っても未回収の謎が1つ以上残っているか
   - □ 最大の答えを転より前に漏らしていないか
   - □ 転の後に「あたたかい結」が1〜2分あるか(泣かせっぱなしで終わっていないか)
   - □ 伏線が全回収されているか
   - □ 抽象語で泣かせようとしていないか
   - □ 元エッセイの固有設定を流用していないか
   - □ 第6部の直近被り除外リストに違反していないか

## 第6部:直近10本ローテーション管理(被り防止の中核)

### 考え方
視聴者が「またこの話か」と感じるのは、全履歴との重複ではなく**直近に見た数本との類似**。したがって管理は「使用済みを永久排除」ではなく「直近N本のクールダウン(冷却期間)」方式にする。冷却期間が明ければ再使用してよい。

### 軸ごとの冷却本数(選択肢の数に応じて設定)
**管理の単位は原則「具体の一文要約」であり、軸名・カテゴリ名ではない。**カテゴリ名で縛るとリストが閉じてローテーション化し、多様性がかえって死ぬ(前提:各リストは開いたリスト)。カテゴリ名での冷却は、視聴者が型として認識しやすい軸(エンジン、転の仕掛け、結末)にのみ適用する。

| 軸 | 管理単位 | 冷却期間 | 備考 |
|---|---|---|---|
| 関係性(軸A) | 関係性そのもの | 直近10本 | 主軸。最優先で管理 |
| 節目イベント(軸E) | 具体の節目 | 直近10本 | リスト外の節目は自動的に被りなし |
| 象徴アイテム(軸F) | **具体物の一文要約** | 直近10本 | カテゴリの連続は具体が違えば可(卵焼き→ナポリタンはOK、卵焼き→卵焼きはNG) |
| 転の仕掛け(軸I) | 型名+一文要約の両方 | 直近10本 | **最重要。**型が同じでも具体が遠ければ可、ただし型の3連続は禁止 |
| エンジン | 型名 | 直近5本 | 16種に拡張したため冷却も延長 |
| 感情の変換(軸G) | 型名 | 直近5本 | |
| 結末の型(軸H) | 型名 | 直近3本 | |
| 舞台・背景(軸B) | 具体の一文要約 | 直近4本 | |
| 時代設定+時間の扱い(軸D) | 時代×(またぐ/またがない/一日もの) | 直近3本 | 「現代・またがない」が続きすぎないかも見る |
| 冒頭の仕掛け | 冒頭文の一文要約 | 直近5本 | 「葬式で遺品発見」が続くと即バレる |

※型名管理の軸で「冷却期間>選択肢数の50%」にすると枯渇するため注意。

### 管理表の形式(スプレッドシート)
1行=1作品。列:通し番号/公開日/タイトル/関係性/エンジン/節目/仕掛け/アイテム/変換/結末/背景/時代/冒頭の仕掛け(一文要約)/転の内容(一文要約)
→ 新規作成時は直近10行をフィルタし、テンプレートの【直近被り除外】欄にコピペするだけ。この転記を1回サボると収束が始まるので、制作フローに機械的に組み込む。

### 「一文要約」で管理する理由(再掲・徹底)
軸名(例:「記録の発見」)だけ管理しても、「日記を見つける」「手紙を見つける」「録音を見つける」が連続すれば視聴者には同じに見える。逆に、軸名だけで縛ると「卵焼きの話は当分できない」という不要な制約が生まれる。**具体レベルの一文要約**(「亡母の日記に自分の弁当の改良メモ」等)を管理単位にすることで、被り防止と発想の自由を両立させる。

## 第7部:2段階生成フロー(品質の底上げ)

100本すべてを高品質にする鍵は、本文を書かせる前の**プロット段階での選別**。一発で本文まで出させると長尺後半の息切れ・伏線回収の雑さが混入し、打率は3〜4割に落ちる。

### フロー
```
STEP1:変数抽選
　管理表から直近被り除外リストを転記 → 各軸からランダム選択

STEP2:プロット生成(ここで量産)
　指示:「本文は書かず、以下のみ出力せよ。
　　①6幕それぞれの内容(各100字)と想定尺
　　②仕込む伏線3つと回収箇所
　　③冒頭コールドオープンの文面(150字・完成稿レベル)
　　④転の2段階開示の設計(事実→裏の想い)
　　⑤結の着地イメージ」
　→ 1案あたり数百字なので、10案を一気に出させて比較するのも有効

STEP3:人間による選別(最重要工程)
　判断基準:「転が既出要素の再解釈で成立しているか(納得感)」「冒頭150字で続きが
　気になるか」「自分の家族を思い出すか(エモさ)」。承認率6〜7割を想定。
　ボツ案は変数を変えて再抽選。型を破った案でも、納得感とエモさが上回るなら採用してよい

STEP4:本文生成(幕ごと分割)
　承認プロットを渡し、幕①〜③を生成→確認→幕④〜⑥を生成。
　分割時は「ここまでの本文全文+プロット」を毎回添付(一貫性維持)

STEP5:完成チェック
　第5部チェックリスト+直近被り除外リストとの照合 → 管理表に1行追記
```

### 運用上の注意
- STEP3を飛ばして全自動化しない。プロット選別は1本1〜2分で済み、ここが品質の9割を決める
- 週次でSTEP2を10〜15案まとめて出し、良い順に承認ストックを作っておくと、日々の制作はSTEP4以降だけで回る
- 視聴維持率データが取れたら「離脱が起きた幕」を管理表に追記し、同じ構成癖を次回の禁止事項に反映する(広告A/Bテストと同じ改善ループ)
