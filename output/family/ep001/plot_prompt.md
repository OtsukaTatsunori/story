# 物語設計書　family / ep001

## 1. コンセプト

嫁（瑞穂）が、二十三年間なじれ続けた姑（芳子）の遺品整理を通して、
その理不尽な「味付け直し」が実は夫の命を守るための偽装だったと知り、憎しみが尊敬に変わる話。
新しさ——嫁姑ものを「和解」ではなく「和解が永遠に間に合わなかった非対称の愛」で描く。姑は真意を告げぬまま死に、真実を知るのは嫁と視聴者だけ。夫は最後まで、自分がなぜ生きているかを知らない。

## 2. 選択要素と組み合わせの狙い

- **関係性**：嫁と姑（田島瑞穂と芳子）。感動系で手薄な鉱脈。母子でも夫婦でもない「選んで家族になったわけではない女二人」の距離が主軸。
- **主エンジン**：気づかれない愛の完遂。姑の愛は、守られた当人（息子・耕一）には生涯届かない。届くのは嫁と視聴者だけ——ここに切なさと尊さが宿る。
- **副エンジン**：償い。姑がなぜ真意を隠し通したのかの動機。姑は若い頃、郷里の濃い味付けで夫を早くに脳卒中で亡くした（と思い込んでいる）。その罪悪感が「私が息子を殺しかけた女だと嫁に知られたくない」という沈黙を生む。＝**新情報のちゃぶ台返しではなく、全行動を一本で説明する動機**。
- **舞台・背景**：遺品整理・実家の片付け（現在軸の装置）。台所と帳面が舞台。背景は主題化させない。
- **視点人物**：当事者本人（嫁・瑞穂の一人称）。語り手自身が真実に対して盲目だったからこそ、視聴者は語り手と同じ速度で誤解し、同じ瞬間に崩れる。
- **時代設定**：平成初期に嫁いだ女の三十余年（現在は令和）。
- **時間の扱い**：二時代をまたぐ回想構成。現在（遺品整理）⇄過去（確執の日々）を往復。
- **節目**：看取り（嫁が姑を看取った）。嫁姑固有の節目がリストにないため看取りを転用。憎みながら最後まで介護し看取った、という事実自体が後で刺さる伏線になる。
- **象徴アイテム（具体物）**：**嫁の味噌汁を、姑が毎朝ただ一口だけすすって「薄めなさい」と突き返した、その一杯**。理不尽の象徴が、真実判明後は愛の象徴に反転する。
- **感情の変換**：反発→尊敬。憎しみが一瞬で愛に化ける嘘はつかない。行き着くのは「好き」ではなく「敵わなかった」という尊敬と畏れ。
- **結末の型**：循環型。冒頭＝遺品の帳面を開く瑞穂に戻り、同じ数字が全く違う意味で見える。最後は瑞穂自身が息子の嫁の味噌汁を一口すすり「薄めなさい」と言う——継承の余韻。
- **転の仕掛け**：誤解の反転（冷たい行動の真意が真逆だった）。装置は記録の発見（二十三年分の血圧と味付けの帳面）。
- **冒頭の仕掛け**：数字の謎型。遺品の帳面に並ぶ二十三年分の数字（血圧）の意味を伏せて開幕する。

**化学反応**：嫁姑の「味付け」という最も陳腐化しやすい題材を、①血圧という理系の数字、②償いという隠れた動機、③本人に永遠に届かない愛、で三重に脱臭している。視聴者は序盤「またある意地悪な姑の話か」と誤読する。その誤読こそが仕掛け——誤読していた分だけ、転で反転の落差が大きくなる。

## 4. キャラの声の設計

- **瑞穂（嫁・語り手／平成初期は20代→現在62歳）**：標準語。折り目正しいが、地の文では本音がこぼれる（「意地の悪い人だと思っていた」）。欠点＝我慢を美徳にして相手の真意を見ようとしなかった鈍さ。後悔＝生前ついに好きになれなかったこと。口癖「……とだけ、言った」（姑の寡黙を語るときの型）。**その人しか言わない一言**（看取り後の一度だけ）「お義母さん、私、まだ薄くできますよ」
- **芳子（姑／昭和一桁生まれ、東北の在の出）**：訛りを一語だけ残す（「しょっぱい」を「しょわい」と言う）。極端に言葉が少ない。命令形でなく体言止めで突き放す。**その人しか言わない一言**（山場で一度だけ、看取りで）「……ごめんね、瑞穂さん」——生涯で唯一嫁に頭を下げた言葉。
- **耕一（夫・芳子の息子／現在65歳）**：軽い。場を丸くする冗談で母と嫁の間を素通りする。悪気なく鈍感。「お袋の舌は昔から気難しいんだ」が口癖。彼が最後まで真実を知らないことが、この話の切なさの器。
- **明日香（孫の嫁／現在／終幕のみ）**：現代的な軽い敬語。瑞穂に「薄めましょうか」と言われ、きょとんとする——かつての瑞穂の鏡。

## 1. このチャンネル共通のルール（品質最優先。型と衝突したらこちらを優先）

- **転は「再解釈」で作る。** 転で明かす真実は前半に既出の出来事・セリフ・行動の意味が変わるものに限る。
  前半に登場していない人物や事実でひっくり返さない（驚きはあっても納得感がない）
- **伏線は二重性。** 一度目は日常描写として自然に流れ、真相を知った後に思い返すと胸に刺さる。
  「いかにも伏線」な思わせぶりは逆効果
- **行動の一貫性。** 真相判明後、その人物の全行動が一本の動機で説明できること
- **感情の因果を飛ばさない。** 憎しみが一瞬で感謝に変わる展開は嘘くさい。
  転の後、感情が変わるまでの戸惑い・沈黙・時間経過を必ず描く
- **語りすぎない。** 一番言いたいことほどセリフやナレーションで説明しない。行動・物・沈黙に語らせる。
  「愛していた」と書いた瞬間にエモさは死ぬ
- **具体の力。** 固有名詞・金額・方言・言い間違いなど時代を感じるディテールを15個以上（時代設定と整合させる）
- **「愛」「絆」「感謝」「家族の大切さ」等の抽象語を地の文で使わない**
- 語り手に欠点・後悔を持たせる（美化された聖人にしない）。教訓を直接言語化しない
- 実在の企業・人物を想起させる設定、時代錯誤（昭和にLINE等）は禁止

## 2. 基本構成（起承転結×六幕）

尺は朗読20〜30分（本文6,000〜9,000字。目安300字/分）。設計書の六幕構成に従い、以下を厳守：

- **①コールドオープン(5%)**: 転の直前シーンを一瞬見せて時間を巻き戻す。状況説明・自己紹介から入らない。
  冒頭150字（30秒）で「結末への予感」か「強い違和感」を置く
- **②日常(15%)**: 人物の性格を具体エピソードで見せる。3分以内に小さな違和感を1つ
- **③亀裂(20%)**: 10分地点に小さな開示（謎を1つ返して1つ開く）
- **④深化(20%)**: 各場面にミニ感情の山。同一シーン4分以上禁止。場面転換は「それから五年後——」と明示ジャンプ
- **⑤転(25%)**: 20分地点が転の入口。最大の謎の回収は「事実→その裏の想い」の2段階で
- **⑥結(15%)**: 転（涙）の後、日常が続いていく描写を1〜2分。最終カットは必ず上向き
  （継承・感謝・新しい朝）。読後感を「切ない」から「あたたかい」に変換する

**オープンループ常時1個以上**: どの時点で切っても未回収の謎が最低1つ残っている状態を維持。
全部回収し終わるのは⑤の終わりだけ。

## 3. 視聴者ターゲット

50〜60代の男女。中学生でも聴いて分かる平易さに、人生経験のある大人にだけ刺さる深みを両立させること。
難しい言葉、複雑すぎる時系列操作は避ける。重厚感は語彙ではなく、間・沈黙・積み重ねで出すこと。
普遍的な家族の風景（食卓、送り迎え、口癖）を必ず織り込み、視聴者自身の家族の記憶と接続させること。

## 4. 出力形式

1. 幕ごとの詳細プロット（各幕に見出し・想定尺(分)を付ける）
2. 仕込んだ伏線と回収箇所の一覧（一度目の見せ方／回収位置／再解釈後の意味）
3. 転の2段階開示の設計（まず明かされる事実→次に見えてくる裏の想い）
4. 冒頭コールドオープンの文面（150字・完成稿レベル）
